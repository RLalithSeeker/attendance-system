# Recognition integration and failure policy

1. Locate proven real face-identity matcher, enrollment implementation and model weights. Distinguish person/object detector, face detector, DeepFace/InsightFace identity matcher and person cross-camera Re-ID. Record actual imports and model licenses. Prefer existing real identity path; no model training required if pretrained matcher actually works.
2. Design slim adapter with `available()`, `enroll()`, `identify()` and typed outcomes matched/unknown/ambiguous/unavailable. Implement only against verified symbols. Never create fake IDs from track IDs, filename, bounding box, VLM, metadata or client request.
3. Capture one face per frame initially. Enrollment 3–5 voluntarily supplied captures if supported, quality check for blur, angle, face size; do not assume number/threshold is validated. Duplicate-person enrollment across student IDs gets flagged for review, not silently merged.
4. Matching: calibrated threshold and nearest-vs-second-nearest ambiguity gap from a representative, permissioned validation set; model/library metric direction matters (distance lower vs similarity higher). Store threshold, metric, model_version and test calibration. Without calibration choose conservative review-only mode, NOT automatic marking. Report false-accept/false-reject counts on consented tests and avoid generalized accuracy claims.
5. Require stable match across e.g. 2–3 recent observations where available; ensure no duplicate events. This is stability, NOT anti-spoofing. Unknown, tie, low quality, no face, multiple faces, revoked consent, out-of-roster, model failure and offline/cloud failure must reject automatic attendance and display clear teacher action.
6. Consent withdrawal: disable recognition immediately and delete or securely retire matching templates according to policy; no stealth re-enrollment. Templates are biometric data. Avoid photos or templates in cloud unless specifically justified and authorized.
7. Test with mock outputs for business logic; run real model tests only with permissioned samples and document actual measured outcomes. Never assert recognition works from successful face detection alone.
